# 1262. 可被三整除的最大和：余数的舞蹈

## 1. 审题（Problem）

### 1.1 约束解码
给你一个整数数组 `nums`，请你找出并返回能被 3 整除的元素最大和。
*   **被 3 整除**：即 `sum % 3 == 0`。
*   **元素最大和**：我们需要尽可能多地选大数，但必须满足整除条件。

### 1.2 边界陷阱
*   没有元素能组成被 3 整除的和（返回 0）。
*   所有元素和本身就被 3 整除（直接返回 sum）。
*   数组包含 0。

### 1.3 问题归类
*   **动态规划 (DP)**。
*   **有限状态机 (Finite State Machine)**。
*   **数学 (Modulo Arithmetic)**。

## 2. 思维演化（Reasoning）

### 2.1 方案 A：回溯 / 如果选
每个数选或不选，找出所有组合。
*   $O(2^N)$，肯定超时。

### 2.2 方案 B：贪心（不明智）
先把所有正数加起来，看余数是 1 还是 2。
*   如果是 1，就减去最小的 `rem=1` 的数，或者减去两个 `rem=2` 的数。
*   这其实是可行的！但不仅要记录最小，还要记录次小，稍微麻烦点。

### 2.3 方案 C：动态规划（推荐）
我们在遍历数组时，只关心**当前的和对 3 取余是多少**。
定义 `dp[0], dp[1], dp[2]` 分别表示余数为 0, 1, 2 的最大和。
遍历每一个数字 `num`：
*   对于之前的每个状态 `dp[i]`，如果我们加上 `num`，新的和是 `dp[i] + num`。
*   新的余数是 `(i + num) % 3`。
*   我们要更新这个新余数对应的最大和。

## 3. 直觉培养（Intuition）

### 3.1 三个桶
想象你有三个桶，分别贴着标签 `0`、`1`、`2`。桶里装的是“当前余数为该标签的最大金币数”。
每来一个新的金币（数字），你都试着把它丢进这三个桶里的原有金币堆里，看看能不能凑出更高的高度，并把新高度记录到对应的新桶里。

![可被三整除的最大和动画](animation.mp4)

**可视化重点**：
1.  **状态转移**：箭头从 `DP[Rem i]` 指向 `DP[Rem (i+num)%3]`。
2.  **更新逻辑**：只有当 `DP[i] + num > DP[next]` 时才更新。初始时非 0 余数的 DP 值为无穷小（或不可达）。

## 4. 代码实现（Solution）

```go
func maxSumDivThree(nums []int) int {
    // dp[i] 表示余数为 i 的最大和
    // 初始化：dp[0]=0, dp[1] 和 dp[2] 为最小值（代表不可能）
    dp := [3]int{0, -1000000, -1000000} // 用一个足够小的负数表示不可达
    
    for _, num := range nums {
        // 需要用临时数组，因为更新是基于上一轮的状态
        nextDp := dp 
        for i := 0; i < 3; i++ {
            currentSum := dp[i] + num
            remainder := currentSum % 3
            if currentSum > nextDp[remainder] {
                nextDp[remainder] = currentSum
            }
        }
        dp = nextDp
    }
    
    return dp[0]
}
```

### 4.2 复杂度分析
*   **时间复杂度**: $O(N)$。遍历一次数组。
*   **空间复杂度**: $O(1)$。只用了大小为 3 的数组。

### 5.2 模运算的性质
`(a + b) % k = ((a % k) + (b % k)) % k`。
这是处理整除、循环数组索引等问题的基石。
