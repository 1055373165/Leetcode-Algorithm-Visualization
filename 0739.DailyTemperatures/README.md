# 739. Daily Temperatures：单调栈的“等待线”

![Daily Temperatures Animation](animation.mp4)

## 1. 审题（Problem）

### 1.1 约束解码
给定一个整数数组 `temperatures`，表示每天的温度，返回一个数组 `answer`，其中 `answer[i]` 是指对于第 `i` 天，下一个更高温度出现在几天后。如果之后都没有更高的温度，则为 `0`。
*   **输入**：数组 `temperatures`。
*   **输出**：数组 `answer`，长度与输入相同。
*   **核心**：寻找 **Next Greater Element (NGE)** 的距离。

### 1.2 边界陷阱
*   数组长度为 1：没有下一次，返回 `[0]`。
*   温度递减：所有位置都是 `0`。
*   温度递增：每个位置都是 `1`（除了最后一个）。

### 1.3 问题归类
寻找右边第一个比自己大的元素，这是 **单调栈（Monotonic Stack）** 的典型应用场景。

## 2. 思维演化（Reasoning）

### 2.1 暴力解法
对于第 `i` 天，向后遍历 `j = i+1` 到 `n-1`，找到第一个 `temps[j] > temps[i]`，计算 `j - i`。
*   双层循环。
*   时间复杂度：$O(N^2)$。如果是倒序排列的数组（如 `[99, 98, ..., 1]`），效率极差。

### 2.2 逆向思维
我们可以维护一个 **“等待列表”**。
遍历每一天，如果当前温度比“等待列表”中某一天要高，说明那一天“等到了”更高的温度，可以结算了。
因为我们总是想先结算“最近”加入等待列表的那一天（Last In, First Out），所以这个等待列表不仅是一个栈，而且栈里的温度应该是 **单调递减** 的。

### 2.3 单调栈推演
*   **栈存储什么？** 存储 **下标（Index）**，因为我们需要计算距离（`current_index - stack_top_index`）。
*   **虽然存储下标，但比较的是温度**。
*   **单调性**：栈底到栈顶，温度依次降低。
    *   来了一个新元素 `T`。
    *   如果 `T <= 栈顶温度`：`T` 没法帮栈顶解套，不仅如此，`T` 也要入栈等待更高的温度。且 `T` 比栈顶更小（或相等）且更晚出现，符合单调递减。
    *   如果 `T > 栈顶温度`：`T` 是栈顶元素的“救星”。栈顶元素出栈，计算距离。重复此过程，直到栈为空或 `T <= 新栈顶`。最后 `T` 入栈。

## 3. 直觉培养（Intuition）

### 3.1 排队观影（Waiting Line）
想象一群人排队按身高进场，但规则是：**你必须只能看到比你高的人才能离队**。
*   A(170) 来了，没人比他高，站着等。
*   B(165) 来了，A 看不到 B（B比A矮），B 也站着等。此时队列：`[A(170), B(165)]`。
*   C(175) 来了！
    *   B 看到 C 了（175 > 165），B 离队。
    *   A 看到 C 了（175 > 170），A 离队。
    *   C 没人比他高，C 进队等着。此时队列：`[C(175)]`。

## 4. 代码实现（Solution）

### 4.1 核心代码（Go）

```go
func dailyTemperatures(temperatures []int) []int {
	n := len(temperatures)
	answer := make([]int, n)
	stack := []int{} // 存储下标

	for i, t := range temperatures {
		// 当栈不为空，且当前温度大于栈顶下标对应的温度
		for len(stack) > 0 && t > temperatures[stack[len(stack)-1]] {
			idx := stack[len(stack)-1]
			stack = stack[:len(stack)-1] // Pop
			answer[idx] = i - idx        // 结算距离
		}
		stack = append(stack, i) // Push
	}
	return answer
}
```

### 4.2 复杂度分析
*   **时间复杂度**：$O(N)$。虽然有两层循环（`for` 和 `while`），但每个元素最多 **入栈一次，出栈一次**。
*   **空间复杂度**：$O(N)$。栈在最坏情况下（单调递减）需要存储所有元素。
