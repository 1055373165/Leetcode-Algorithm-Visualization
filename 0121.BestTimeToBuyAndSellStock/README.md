# 121. 买卖股票的最佳时机：贪心的智慧

## 1. 审题（Problem）

### 1.1 约束解码
给定一个数组 `prices`，它的第 `i` 个元素 `prices[i]` 是一支给定股票第 `i` 天的价格。
你只能选择 **某一天** 买入这只股票，并选择在 **未来的某一个不同的日子** 卖出该股票。
设计一个算法来计算你所能获取的最大利润。如果不交易，利润为 0。

### 1.2 边界陷阱
*   价格持续下跌（最佳利润为 0，不能亏本买卖）。
*   价格先跌后涨。
*   只有一天（无法买卖）。

### 1.3 问题归类
*   **数组 (Array)**。
*   **动态规划 (DP)**（虽然通常用贪心优化到 $O(1)$ 空间）。
*   **贪心 (Greedy)**。

## 2. 思维演化（Reasoning）

### 2.1 方案 A：暴力法
双重循环，枚举每一天买入，再枚举未来的每一天卖出，找差值最大的。
*   时间复杂度 $O(N^2)$。容易超时。

### 2.2 方案 B：一次遍历（记录历史最低）
假设我们在第 `i` 天卖出，那要在哪天买入最划算？当然是第 `i` 天之前的**最低价**的那一天。
所以我们只需要遍历价格数组，同时维护两个变量：
1.  `minPrice`：目前为止遇到的最低价格。
2.  `maxProfit`：目前为止可能的最大利润（当前价格 - `minPrice`）。

## 3. 直觉培养（Intuition）

### 3.1 寻找波谷
这就像是在爬山。你想在山谷最低点买入，在之后的山峰最高点卖出。
*   每走一步，你都看看脚下是不是比之前走过的更低（更新 `minPrice`）。
*   同时看看现在的高度减去之前的最低点，利润是不是比之前记录的更大（更新 `maxProfit`）。

**可视化重点**：
1.  **最低价追踪**：红色虚线表示“历史最低价”。每当遇到更低的价格，虚线就更新并下移。
2.  **利润计算**：每一天的柱子与红色虚线的高度差，就是如果在这一天卖出的利润。
3.  **最大利润**：绿色高亮显示曾经出现过的最大高度差。

## 4. 代码实现（Solution）

```go
func maxProfit(prices []int) int {
    if len(prices) == 0 {
        return 0
    }
    
    // 初始化最低价为无穷大
    minPrice := int(^uint(0) >> 1)
    maxProfit := 0
    
    for _, p := range prices {
        // 如果当前价格比之前的最低价还低，更新最低价
        if p < minPrice {
            minPrice = p
        } else if p - minPrice > maxProfit {
            // 否则，看看如果在今天卖出能不能赚更多
            maxProfit = p - minPrice
        }
    }
    
    return maxProfit
}
```

### 4.2 复杂度分析
*   **时间复杂度**: $O(N)$。只需要遍历一次数组。
*   **空间复杂度**: $O(1)$。只用了两个变量。

## 5. 融会贯通（Mastery）

### 5.1 变体题群
股票系列是 DP 的经典题库：
| 题目 | 关键词 | 解法微调 |
| :--- | :--- | :--- |
| **121. 买卖一次** | 一次交易 | 记录 `minPrice` |
| **122. 买卖无限次** | 无限交易 | 贪心：只要涨了就卖，收集所有上坡利润 `max(0, p[i]-p[i-1])` |
| **123. 买卖两次** | 最多两次 | DP `dp[k][0/1]` 状态机 |
| **188. 买卖 K 次** | 最多 K 次 | 通用 DP |
| **309. 含冷冻期** | 卖后歇一天 | 状态机增加 `cooldown` 状态 |
| **714. 含手续费** | 每次手续费 | 利润公式减去 `fee` |

### 5.2 核心思想
**贪心 + 状态记录**。
对于只能买卖一次的情况，只要记住“过去最便宜的时候”，就能算出“现在卖划不划算”。
