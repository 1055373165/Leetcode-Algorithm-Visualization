# 131. 分割回文串：回溯的艺术

## 1. 审题（Problem）

### 1.1 约束解码
给你一个字符串 `s`，请你将 `s` 分割成一些子串，使每个子串都是 **回文串**。返回 `s` 所有可能的分割方案。
*   **回文串**：正着读和倒着读一样的字符串。
*   **分割**：将字符串切几刀，切出来的每一段都必须是回文。

### 1.2 边界陷阱
*   `s` 为空（约束 `1 <= s.length <= 16`，无需考虑）。
*   全一样的字符（如 `aaa`，分法很多）。
*   没有任何回文子串（除了单个字符，单个字符本身总是回文）。

### 1.3 问题归类
*   **回溯 (Backtracking)**。
*   **深度优先搜索 (DFS)**。
*   **动态规划 (DP)**（用于预处理回文判断）。

## 2. 思维演化（Reasoning）

### 2.1 方案 A：暴力枚举所有切割点
对于长度为 $N$ 的字符串，有 $N-1$ 个空隙可以切，每个空隙切或不切，共有 $2^{N-1}$ 种切法。
我们需要枚举每一种切法，然后检查每一段是否是回文。

### 2.2 方案 B：回溯法（标准解）
这是一个典型的“在决策树上找路径”的问题。
*   **当前层级**：我们在剩下的字符串 `s[start:]` 中，尝试截取一个前缀 `s[start...i]`。
*   **剪枝条件**：如果这个前缀是回文，我们才有资格继续往下递归，处理剩下的 `s[i+1:]`。
*   **回溯**：如果我们尝试了截取 `s[start...i]` 发现走不通（或者已经找到一组解），我们需要撤销这个选择，尝试 `s[start...i+1]`。

### 2.3 优化：记忆化回文判定
在回溯中，我们会频繁询问 `s[i...j]` 是否是回文。如果不优化，每次判定需要 $O(N)$。
我们可以预处理一个二维数组 `dp[i][j]` 表示 `s[i...j]` 是否为回文，查询变 $O(1)$。

## 3. 直觉培养（Intuition）

### 3.1 切蛋糕
想象你在切一条长条蛋糕。
*   你这一刀切下去，拿到手里的这一块必须是“完美的”（回文）。
*   如果切下来的这块不完美，那就不能切，这一刀得往后挪一挪试试。
*   如果你切了一块完美的，把剩下的蛋糕交给下一个人，让他继续切。
*   如果最后蛋糕分完了，大家手里的都是完美的，那这就是一种成功的切法。

## 4. 代码实现（Solution）

```go
func partition(s string) [][]string {
	var res [][]string
	var path []string
	
	// DFS 函数
	// start: 当前处理到的字符索引
	var dfs func(start int)
	dfs = func(start int) {
		// Base Case: 如果切到了字符串末尾，说明找到了一种可行切法
		if start == len(s) {
			// 需要拷贝 path，因为 path 底层数组会变
			temp := make([]string, len(path))
			copy(temp, path)
			res = append(res, temp)
			return
		}

		// 尝试切出前缀 s[start ... i]
		for i := start; i < len(s); i++ {
			// 截取子串
			sub := s[start : i+1]
			
			// 判断是否回文（这里简化直接判断，也可以用 DP 优化）
			if isPalindrome(sub) {
				// 做选择
				path = append(path, sub)
				// 递归进入下一层，处理剩下的字符串
				dfs(i + 1)
				// 撤销选择（回溯）
				path = path[:len(path)-1]
			}
		}
	}

	dfs(0)
	return res
}

func isPalindrome(s string) bool {
	for i, j := 0, len(s)-1; i < j; i, j = i+1, j-1 {
		if s[i] != s[j] {
			return false
		}
	}
	return true
}
```

### 4.2 复杂度分析
*   **时间复杂度**: $O(N \cdot 2^N)$。最坏情况下（如 "aaa"）每个分割点都可能产生有效分支。
*   **空间复杂度**: $O(N)$。递归栈深度和路径记录。

### 5.2 回溯模版
```go
func backtrack(路径, 选择列表) {
    if 满足结束条件 {
        result.add(路径)
        return
    }
    for 选择 in 选择列表 {
        做选择
        backtrack(路径, 选择列表)
        撤销选择
    }
}
```
掌握这个模版，可以秒杀 90% 的排列组合问题。
