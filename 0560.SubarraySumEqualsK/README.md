# 560. 和为 K 的子数组：前缀和与哈希表的完美共舞

## 1. 审题（Problem）

### 1.1 约束解码
给定一个整数数组 `nums` 和一个整数 `k`，你需要找到该数组中**连续**子数组的个数，使得该子数组的和为 `k`。
*   **连续**：子数组必须是原数组中一段连续的元素。
*   **整数**：包含正数、负数和 0。这意味着前缀和不一定是单调递增的（无法使用滑动窗口）。

### 1.2 边界陷阱
*   `nums` 为空？（题目提示 `1 <= nums.length`，所以不用考虑）
*   `k` 可以为负数或 0。
*   和可能溢出？（题目提示和在 32 位有符号整数范围内）。

### 1.3 问题归类
*   **前缀和 (Prefix Sum)**。
*   **哈希表 (HashMap)**。

## 2. 思维演化（Reasoning）

### 2.1 方案 A：暴力枚举
枚举所有可能的子数组 `[i..j]`，计算它们的和。
*   三层循环：$O(n^3)$。
*   优化求和过程（预计算前缀和）：$O(n^2)$。但对于 $2 \times 10^4$ 的数据规模，依然会超时。

### 2.2 方案 B：滑动窗口？
如果数组全是正数，我们可以用滑动窗口。当窗口和小于 `k` 右移 `r`，大于 `k` 左移 `l`。
**但是**，数组包含负数。加一个负数，和变小；减一个负数，和变大。单调性被破坏，滑动窗口失效。

### 2.3 方案 C：前缀和 + 两数之和（完美解）
我们定义 `pre[i]` 为 `nums[0..i]` 的和。
那么子数组 `nums[j..i]` 的和可以表示为：
$$
Sum(j, i) = pre[i] - pre[j-1]
$$
我们要找的就是满足条件 `Sum(j, i) == k` 的 `(j, i)` 对数。
公式变形：
$$
pre[i] - pre[j-1] = k \\
pre[j-1] = pre[i] - k
$$
**这不就是“两数之和”吗？**
当我们遍历到 `i` 时，`pre[i]` 是已知的，`k` 是已知的。如果不考虑寻找的效率，我们需要回过头去数组里找有多少个 `pre[j-1]` 等于 `pre[i] - k`。
为了将查找时间从 $O(n)$ 降到 $O(1)$，我们使用**哈希表**记录之前出现过的所有前缀和的次数。

## 3. 直觉培养（Intuition）

### 3.1 穿越时空的握手
想象你在走一条上下起伏的路。
*   你当前的高度是 `H_curr`。
*   你想知道：之前有没有某个时刻，我的高度是 `H_prev`，使得 `H_curr - H_prev = k`？
*   如果有，那么从那个时刻走到现在，高度差正好是 `k`。

![和为K的子数组动画](animation.mp4)

**关键点**：
*   我们不需要知道具体的 `j` 在哪，只需要知道有多少个 `j` 满足条件。
*   **初始化**：`map[0] = 1`。这代表“空数组的前缀和为 0”。如果 `pre[i] == k`，那么 `pre[i] - 0 = k`，这也是一种合法情况（从头开始的子数组）。

## 4. 代码实现（Solution）

```go
func subarraySum(nums []int, k int) int {
	// Key: 前缀和, Value: 该前缀和出现的次数
	// 初始化 {0: 1} 是为了处理从数组开头就开始匹配的情况 (pre[i] - 0 = k)
	preMap := map[int]int{0: 1}
	count := 0
	pre := 0

	for _, num := range nums {
		pre += num
		
		// 核心公式：pre[j-1] = pre[i] - k
		// 查找之前是否出现过目标前缀和
		if c, ok := preMap[pre-k]; ok {
			count += c
		}

		// 更新当前前缀和的计数
		preMap[pre]++
	}

	return count
}
```

### 4.2 复杂度证明
*   **时间复杂度**: $O(n)$。一次遍历，哈希表操作均为 $O(1)$。
*   **空间复杂度**: $O(n)$。最坏情况（所有前缀和都不同）下，哈希表存储 $n$ 个元素。

### 4.3 易错点清单
1.  **Map 初始化**：忘记 `preMap[0] = 1`。这将漏掉所有从索引 0 开始的解。
2.  **更新时机**：必须**先**查 Map，**再**更新 Map。因为子数组长度至少为 1，不能用当前的前缀和减去它自己（那意味着空数组）。
