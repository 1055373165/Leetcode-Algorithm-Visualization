# 5. 最长回文子串：中心扩散的对称美学

## 1. 审题（Problem）

### 1.1 约束解码
题目要求在一个字符串中找到 **最长** 的 **回文** 子串。
数据范围：$1 \le s.length \le 1000$。
这个规模意味着 $O(n^2)$ 的算法是可以接受的（$10^6$ 次操作），但 $O(n^3)$ 可能有点勉强（$10^9$ 次操作）。这暗示我们至少要优化掉一层循环。

### 1.2 边界陷阱
*   **空串/单字符**：直接返回自身。
*   **全字符相同**："aaaaa"，整个串就是回文。
*   **偶数长度回文**："abba"，中心不在某个字符上，而是在两个字符之间。这一点是必须要处理的核心差异。

### 1.3 问题归类
这是一个经典的 **字符串/动态规划** 问题。虽然可以用 DP 解决，但还有一个更直观且空间复杂度更优的解法——**中心扩散法（Center Expansion）**。它利用了回文串天然的对称性。

## 2. 思维演化（Reasoning）

### 2.1 暴力解法：低效的枚举
最朴素的想法是枚举所有可能的子串 $(i, j)$，通过 $O(n)$ 的时间判断它是否是回文。
总复杂度：$O(n^2) \times O(n) = O(n^3)$。
瓶颈在于：我们在判断 "aba" 是回文后，再去判断 "cabac" 时，又重新从头扫描了一遍，完全浪费了 "aba" 已经是回文这个已知信息。

### 2.2 动态规划：空间的代价
我们可以定义状态 $dp[i][j]$ 表示子串 $s[i..j]$ 是否为回文。
转移方程：$dp[i][j] = (s[i] == s[j]) \text{ and } dp[i+1][j-1]$。
这利用了已知信息，将判断时间降为 $O(1)$，总时间 $O(n^2)$。但代价是 $O(n^2)$ 的空间复杂度。如果 $N=1000$，这就需要百万级的 boolean 数组。能不能更省空间？

### 2.3 中心扩散：反向思维
与其“枚举边界再检查内部”，不如“枚举中心向外扩散”。
回文串一定有一个中心。
1.  如果回文长度是奇数，中心是一个字符（例如 "aba"，中心是 'b'）。
2.  如果回文长度是偶数，中心是两个字符的间隙（例如 "abba"，中心是 "bb"）。
3.  我们只需要遍历这 $2N-1$ 个中心（N个字符+N-1个间隙），向两边扩展，直到字符不相等为止。
这样做时间也是 $O(n^2)$，但空间只需要 $O(1)$！这是面试中最优的通用解法（先不谈 Manacher）。

## 3. 直觉培养（Intuition）

### 3.1 镜像效应
想象你在照镜子。回文串就是“左边是右边的镜像”。
中心扩散法就像是：
1.  你站在镜子前（中心点）。
2.  你往左走一步，镜子里的你往右走一步。
3.  如果你们动作一致（字符相同），就继续走；如果不一致，就停下。
这个过程非常符合人类直觉。

## 4. 代码实现（Solution）

**算法图示：中心扩散演示**

![中心扩散动画](animation.mp4)

我们采用中心扩散法。为了处理奇偶长度的差异，我们可以把“一个字符中心”和“两个字符中心”统一抽象为 `expand(left, right)` 函数。

```go
func longestPalindrome(s string) string {
	if len(s) < 2 {
		return s
	}

	start, end := 0, 0

	for i := range s {
		// 情况 1：奇数长度，以 s[i] 为中心
		len1 := expandAroundCenter(s, i, i)
		// 情况 2：偶数长度，以 s[i] 和 s[i+1] 为中心
		len2 := expandAroundCenter(s, i, i+1)

		// 取最大值
		maxLen := max(len1, len2)

		// 如果找到了更长的回文，更新结果
		// 注意：这里的计算逻辑需要仔细推导
		// len 为回文长度。
		// 新 start = center - (len - 1) / 2
		// 新 end   = center + len / 2
		if maxLen > end-start {
			start = i - (maxLen-1)/2
			end = i + maxLen/2
		}
	}

	return s[start : end+1]
}

// expandAroundCenter 向两边扩散，返回回文长度
func expandAroundCenter(s string, left, right int) int {
	// 当 range 合法 且 字符相等时，继续扩散
	for left >= 0 && right < len(s) && s[left] == s[right] {
		left--
		right++
	}
	// 注意：循环结束时，s[left] != s[right] 或者越界
	// 此时回文范围是 (left+1 ... right-1)
	// 长度 = (right - 1) - (left + 1) + 1 = right - left - 1
	return right - left - 1
}
```

### 4.2 复杂度证明
*   **时间复杂度**: $O(n^2)$。我们需要遍历每个中心（$O(n)$），每个中心平均向外扩展 $O(n)$ 次（最坏情况全是相同字符）。
*   **空间复杂度**: $O(1)$。我们只用了几个变量存储索引，没有使用额外的数组。

### 4.3 易错点清单
1.  **扩散边界计算**：`expand` 函数退出循环时，`left` 和 `right` 已经越界或者不匹配了，实际回文范围是 `left+1` 到 `right-1`。长度公式是 `right - left - 1`。
2.  **更新起止点**：当拿到长度 `len` 后，计算 `start` 时要用 `(len-1)/2`。举例：`len=3`，`i`是中心，`start = i - 1`；`len=4`（偶数中心是 `i, i+1`），`start = i - 1`。公式 `i - (len-1)/2` 对奇偶都适用（利用整数除法向下取整特性）。

## 5. 融会贯通（Mastery）

### 5.1 变体题群
| 题目 | 变化点 | 解法调整 |
| :--- | :--- | :--- |
| **5. 最长回文子串** | 求内容 | 中心扩散 或 DP |
| **647. 回文子串** | 求个数 | 中心扩散，每次扩展成功 `count++` |
| **516. 最长回文子序列** | 不连续 | 必须用 DP，$dp[i][j]$ 依赖 $dp[i+1][j-1]$ |

### 5.2 终极解法：Manacher 算法（马拉车）
虽然 $O(n^2)$ 已经足够面试，但存在 $O(n)$ 的神级算法——Manacher。
它的核心思想是利用已经计算过的回文半径，加速后续中心的计算（类似 KMP）。
**面试建议**：除非面试官明确要求 $O(n)$ 或者数据范围极大，否则**不要**直接写 Manacher。代码极其难记且容易写错，且在 $N=1000$ 时优势不明显。能清晰写出 $O(n^2)$ 的中心扩散且 Bug Free 才是最佳策略。
