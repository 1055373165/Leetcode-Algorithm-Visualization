# 27. 移除元素：双指针的极致压缩

## 1. 审题（Problem）

### 1.1 约束解码
给你一个数组 `nums` 和一个值 `val`，你需要**原地**移除所有数值等于 `val` 的元素，并返回移除后数组的新长度。
*   **原地**：不能使用额外的数组空间 ($O(1)$ 空间复杂度)。
*   **顺序**：元素的相对顺序可以改变（虽然保持顺序通常更好）。

### 1.2 边界陷阱
*   数组为空。
*   数组中没有 `val`。
*   数组中全是 `val`。

### 1.3 问题归类
*   **数组 (Array)**。
*   **双指针 (Two Pointers)**：读写指针（快慢指针）。

## 2. 思维演化（Reasoning）

### 2.1 方案 A：暴力移除
遇到一个 `val`，就把后面的所有元素往前挪一位。
*   时间复杂度：$O(N^2)$。每次移除都需要移动大量元素。

### 2.2 方案 B：双指针（读写分离）
我们可以把数组看作两个部分：
1.  **待处理区**（由读指针 `i` 扫描）。
2.  **保留区**（由写指针 `k` 维护）。

我们遍历整个数组：
*   如果当前元素 `nums[i]` **不等于** `val`，说明它是我们要保留的。我们将它**复制**到 `nums[k]` 的位置，然后把写指针 `k` 向后移一位。
*   如果当前元素 `nums[i]` **等于** `val`，说明它是垃圾。我们直接跳过（不管它，读指针 `i` 继续走）。

这样，当 `i` 走完时，`0` 到 `k-1` 的位置就是所有保留下来的元素。

## 3. 直觉培养（Intuition）

### 3.1 垃圾分类员
想象你在传送带旁分拣垃圾。
*   传送带（`i`）：源源不断地送来元素。
*   收集箱（`k`）：只存放有用的东西。
*   遇到垃圾（`val`）：直接丢掉（跳过）。
*   遇到好东西（`!= val`）：扔进收集箱（写入 `nums[k]`），箱子空间 +1。

## 4. 代码实现（Solution）

### 4.1 读写双指针（保留顺序）

```go
func removeElement(nums []int, val int) int {
	// k 是写指针，指向下一个存放非 val 元素的位置
	k := 0

	// i 是读指针，遍历整个数组
	for i := 0; i < len(nums); i++ {
		if nums[i] != val {
			// 只有当 nums[i] 不是垃圾时，才保留它
			nums[k] = nums[i]
			k++
		}
		// 如果 nums[i] == val，什么都不做，i 继续往后走
	}

	return k
}
```

### 4.2 对撞双指针（不保留顺序，元素移动最少）
如果题目允许改变顺序，且我们要移除的元素很少，可以把末尾的元素填补到被移除的位置。
```go
func removeElementOptimized(nums []int, val int) int {
    left, right := 0, len(nums)
    for left < right {
        if nums[left] == val {
            // 发现垃圾，用最后一个元素覆盖它
            nums[left] = nums[right-1]
            right-- // 数组长度缩小
        } else {
            left++ // 当前元素有效，检查下一个
        }
    }
    return left
}
```

### 4.3 复杂度分析
*   **时间复杂度**: $O(N)$。两个指针最多遍历数组一次。
*   **空间复杂度**: $O(1)$。原地操作。

### 5.2 核心思想
**双指针**是数组原地操作的神器。
*   **快慢指针（读写指针）**：用于过滤、去重。
*   **左右指针（对撞指针）**：用于交换、查找匹配（如 Two Sum）。
