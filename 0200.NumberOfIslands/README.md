# 200. 岛屿数量：沉没大陆的艺术

## 1. 审题（Problem）

### 1.1 约束解码
给你一个由 `'1'`（陆地）和 `'0'`（水）组成的 `m x n` 二维网格，请你计算网格中岛屿的数量。
*   **连通性**：岛屿总是被水包围，并且每座岛屿只能由水平方向和/或竖直方向上相邻的陆地连接形成。
*   **边界**：你可以假设网格的四个边缘都被水包围。

### 1.2 边界陷阱
*   网格为空？（题目约束 `m, n >= 1`，无需从空处理）。
*   全水（0）或全陆地（1）。
*   岛屿形状复杂（环形、凹形等）。

### 1.3 问题归类
*   **图的遍历 (Graph Traversal)**。
*   **深度优先搜索 (DFS)** / **广度优先搜索 (BFS)**。
*   **并查集 (Union Find)**。

## 2. 思维演化（Reasoning）

### 2.1 方案 A：逐个遍历 + 记忆化
我们遍历网格的每一个格子。
*   如果是水（'0'），跳过。
*   如果是陆地（'1'），由于它属于某个岛屿，我们**找到了一座新岛屿**，计数器 +1。
*   **关键问题**：为了不重复计算这座岛屿的其他部分，我们需要把这座岛屿的所有陆地都标记为“已访问”。

### 2.2 方案 B：沉岛策略（Flood Fill）
与其使用一个额外的 `visited` 数组（空间复杂度 $O(MN)$），不如直接修改原数组。
*   当我们遇到一个 `'1'` 时，将其改为 `'0'`（或者 `'2'`，代表已访问）。
*   然后递归地向四周扩散，把所有相连的 `'1'` 都改为 `'0'`。
*   这个过程就像是**把发现的岛屿“沉”入海底**，这样下次遍历到这里时，就是水了，不会重复计数。

## 3. 直觉培养（Intuition）

### 3.1 病毒扩散
想象你是一个病毒，降落在某个绿色的格子上。你会迅速感染上下左右所有相邻的绿色格子，直到遇到蓝色的水为止。
*   每一次“降落”（即在主循环中找到一个 '1'），就代表发现了一个独立的生态系统（岛屿）。
*   随后的“感染”（DFS/BFS），只是为了标记这个系统的范围。

## 4. 代码实现（Solution）

### 4.1 DFS 版本（推荐，代码简短）

```go
func numIslands(grid [][]byte) int {
    if len(grid) == 0 {
        return 0
    }
    
    m, n := len(grid), len(grid[0])
    count := 0
    
    // 定义 DFS 函数
    var dfs func(r, c int)
    dfs = func(r, c int) {
        // 越界或不是陆地，直接返回
        if r < 0 || c < 0 || r >= m || c >= n || grid[r][c] != '1' {
            return
        }
        
        // 标记为已访问（沉岛）
        grid[r][c] = '0' 
        
        // 向四周扩散
        dfs(r-1, c) // 上
        dfs(r+1, c) // 下
        dfs(r, c-1) // 左
        dfs(r, c+1) // 右
    }
    
    // 遍历网格
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if grid[i][j] == '1' {
                count++
                dfs(i, j) // 启动扩散，沉没整座岛
            }
        }
    }
    
    return count
}
```

### 4.2 复杂度分析
*   **时间复杂度**: $O(M \times N)$。每个格子最多被访问两次（一次在主循环，一次在 DFS 中被沉没）。
*   **空间复杂度**: $O(M \times N)$。最坏情况下（全为陆地），DFS 递归栈深度可能达到 $M \times N$。

### 5.2 为什么不用并查集（Union Find）？
*   并查集当然可以做。遍历每个 `'1'`，将其与右边和下边的 `'1'` 合并。最终集数就是岛屿数。
*   但在面试中，DFS/BFS 写法更简洁，不易出错。并查集代码量较大，且需要展平二维坐标，除非题目涉及“动态连接”（比如不断加陆地），否则首选 DFS。
