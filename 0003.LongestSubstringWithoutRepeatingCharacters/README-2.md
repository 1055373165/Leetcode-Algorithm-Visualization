# LeetCode 3. 无重复字符的最长子串（Longest Substring Without Repeating Characters）

---

## 一、题目核心信息

### 题目描述

给定一个字符串 `s`，请你找出其中不含有重复字符的**最长子串**的长度。

**输入**：一个字符串 `s`
**输出**：一个整数，表示最长无重复字符子串的长度

**约束条件**：
- `0 <= s.length <= 5 * 10⁴`
- `s` 由英文字母、数字、符号和空格组成

**示例**：

| 输入 | 输出 | 解释 |
|------|------|------|
| `"abcabcbb"` | `3` | 最长无重复子串是 `"abc"`，长度为 3 |
| `"bbbbb"` | `1` | 最长无重复子串是 `"b"`，长度为 1 |
| `"pwwkew"` | `3` | 最长无重复子串是 `"wke"`，长度为 3 |

### 核心考点

- **滑动窗口**（Sliding Window）
- **哈希表**（HashMap / HashSet）

### 难度等级与思维能力

- **难度**：Medium（中等）
- **考察的思维能力**：
  - **窗口思维**：如何定义一个"有效窗口"并动态维护它
  - **状态追踪**：如何快速判断当前窗口内是否有重复字符
  - **优化意识**：如何从暴力枚举优化到线性扫描

## 二、解题思路分析

### 暴力解法思路

**核心逻辑**：枚举所有可能的子串，逐一检查是否包含重复字符，记录最长的那个。

```
对于每个起始位置 i（0 到 n-1）：
    对于每个结束位置 j（i 到 n-1）：
        检查 s[i..j] 是否所有字符都不重复
        如果不重复，更新最大长度
```

**优缺点**：
- ✅ 思路简单，容易理解
- ❌ 三层循环（枚举起点 × 枚举终点 × 检查重复），时间复杂度 O(n³)
- ❌ 当 `s.length = 50000` 时，运算次数约 `1.25 × 10¹⁴`，**必然超时**

### 最优解法思路：滑动窗口

**关键洞察**：暴力解法做了大量重复工作。当我们知道 `s[i..j]` 没有重复字符时，检查 `s[i..j+1]` 只需看 `s[j+1]` 是否已经在窗口中出现过，而不需要重新检查整个子串。

**思考过程**，分三步理解：

**第一步：把问题想象成一个可伸缩的窗口**

想象你拿着一个可以伸缩的"取景框"放在字符串上。这个取景框有左边界 `left` 和右边界 `right`：
- **右边界不断右移**：每次尝试把一个新字符纳入窗口
- **左边界按需右移**：当新字符和窗口内的某个字符重复时，左边界收缩，直到窗口内没有重复字符

**第二步：如何快速判断"新字符是否在窗口中"**

用一个**哈希表**（字典）记录每个字符**最近一次出现的位置**。当右边界扫到字符 `c` 时：
- 如果 `c` 不在哈希表中，或者 `c` 上次出现的位置在 `left` 左边 → 没有重复，直接纳入窗口
- 如果 `c` 上次出现的位置 ≥ `left` → 有重复！需要把 `left` 跳到 **`c` 上次出现位置的右边一格**

**第三步：为什么 left 可以直接"跳"而不是一步步移动**

因为哈希表记录了每个字符的最新位置。当发现重复时，我们知道必须跳过那个重复字符，所以 `left` 直接跳到 `char_index[c] + 1`。这一步是优化的精髓——把"一步步收缩"变成了"精准跳跃"。

### 思路验证

**用例 1**：`s = "abcabcbb"`

```
right=0, char='a', 哈希表={}, 无重复 → 窗口="a", 哈希表={'a':0}, 最大长度=1
right=1, char='b', 哈希表={'a':0}, 无重复 → 窗口="ab", 哈希表={'a':0,'b':1}, 最大长度=2
right=2, char='c', 无重复 → 窗口="abc", 最大长度=3
right=3, char='a', 'a'上次在位置0, left=0 → 重复！left跳到1 → 窗口="bca", 最大长度=3
right=4, char='b', 'b'上次在位置1, left=1 → 重复！left跳到2 → 窗口="cab", 最大长度=3
right=5, char='c', 'c'上次在位置2, left=2 → 重复！left跳到3 → 窗口="abc", 最大长度=3
right=6, char='b', 'b'上次在位置4, left=3 → 重复！left跳到5 → 窗口="cb", 最大长度=3
right=7, char='b', 'b'上次在位置6, left=5 → 重复！left跳到7 → 窗口="b", 最大长度=3
```

最终结果：**3** ✅

**用例 2**：`s = "pwwkew"`

```
right=0, 'p' → 窗口="p", 最大长度=1
right=1, 'w' → 窗口="pw", 最大长度=2
right=2, 'w', 重复！left跳到2 → 窗口="w", 最大长度=2
right=3, 'k' → 窗口="wk", 最大长度=2
right=4, 'e' → 窗口="wke", 最大长度=3
right=5, 'w', 'w'上次在位置2, left=2 → 重复！left跳到3 → 窗口="kew", 最大长度=3
```

最终结果：**3** ✅

## 三、代码实现

### Python 实现

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        # 特殊情况：空字符串直接返回 0
        if not s:
            return 0

        # 哈希表：记录每个字符最近一次出现的索引位置
        char_index = {}

        # 滑动窗口的左边界
        left = 0

        # 记录最长无重复子串的长度
        max_length = 0

        # right 是滑动窗口的右边界，遍历整个字符串
        for right in range(len(s)):
            char = s[right]

            # 如果当前字符在哈希表中，并且上次出现位置 >= left
            # 说明窗口内有重复字符，需要收缩左边界
            if char in char_index and char_index[char] >= left:
                # 左边界直接跳到重复字符的下一个位置
                left = char_index[char] + 1

            # 更新当前字符的最新位置（无论是否重复都要更新）
            char_index[char] = right

            # 计算当前窗口长度，并更新最大值
            # 窗口长度 = 右边界 - 左边界 + 1
            current_length = right - left + 1
            max_length = max(max_length, current_length)

        return max_length
```

### 代码运行示例

```python
sol = Solution()

# 测试用例 1：普通用例 —— 有多段无重复子串
print(sol.lengthOfLongestSubstring("abcabcbb"))
# 输入: "abcabcbb"
# 输出: 3
# 解释: 最长无重复子串为 "abc"，长度 3

# 测试用例 2：边界用例 —— 所有字符相同

# 输入: "bbbbb"
# 输出: 1
# 解释: 每个字符都重复，最长无重复子串只有单个字符 "b"

# 测试用例 3：普通用例 —— 最长子串在中间
print(sol.lengthOfLongestSubstring("pwwkew"))
# 输入: "pwwkew"
# 输出: 3
# 解释: 最长无重复子串为 "wke" 或 "kew"，长度 3

# 测试用例 4：边界用例 —— 空字符串

# 输入: ""
# 输出: 0
# 解释: 空字符串没有子串，长度为 0

# 测试用例 5：边界用例 —— 单个字符

# 输入: "a"
# 输出: 1
# 解释: 只有一个字符，本身就是最长无重复子串

# 测试用例 6：包含空格和特殊字符

# 输入: "ab c!ab"
# 输出: 5
# 解释: 最长无重复子串为 "b c!a" 或 " c!ab"，长度 5
```

## 四、复杂度分析

### 时间复杂度：O(n)

**详细推导**：

- `right` 指针从 `0` 遍历到 `n-1`，总共移动 **n 次**
- `left` 指针只会向右移动（永远不会回退），在整个过程中**最多**从 `0` 移动到 `n-1`，总共移动 **最多 n 次**
- 哈希表的查找和更新操作均为 **O(1)**
- 因此总时间 = O(n) + O(n) + O(1) × n = **O(n)**

**最坏情况**：`s = "abcdefg...xyz"`（所有字符不同），`right` 移动 n 次，`left` 不移动 → O(n)
**最好情况**：`s = ""`（空字符串），直接返回 → O(1)
**平均情况**：O(n)，因为两个指针各自最多遍历一次字符串

> **对比暴力解法**：从 O(n³) 优化到 O(n)，当 n = 50000 时，从 1.25 × 10¹⁴ 次运算降低到约 10⁵ 次，提升约 **10 亿倍**。

### 空间复杂度：O(min(m, n))

**详细推导**：

- `m` 是字符集大小（英文字母 + 数字 + 符号 + 空格，ASCII 可打印字符共 95 个）
- `n` 是字符串长度
- 哈希表最多存储 `min(m, n)` 个键值对（窗口内不会有重复字符，且字符种类有限）
- 实际应用中，由于字符集有限（最多 128 或 256 个 ASCII 字符），空间可视为 **O(1)**

**是否可以优化空间？**

可以用长度为 128 的数组替代哈希表（因为字符都是 ASCII），空间固定为 O(128) = O(1)。在 Python 中哈希表已经足够高效，但在 C/C++ 等语言中使用数组会有更好的缓存局部性。

### 优化方向

当前的滑动窗口 + 哈希表（记录索引）已经是**最优解法**：

| 方案 | 时间 | 空间 | 说明 |
|------|------|------|------|
| 暴力枚举 | O(n³) | O(n) | 三重循环，完全不可取 |
| 滑动窗口 + HashSet | O(2n) | O(min(m,n)) | left 需要逐步移动，最坏 2n 步 |
| **滑动窗口 + HashMap（本题解法）** | **O(n)** | **O(min(m,n))** | **left 直接跳跃，严格 n 步** |
| 滑动窗口 + 数组（ASCII 优化） | O(n) | O(1) | 用固定数组替代哈希表，常数更小 |

> 注意：使用 HashSet 的方案中，`left` 需要一步步右移并逐个删除字符，最坏情况下 `left` 和 `right` 各走 n 步，总共 2n 步。而使用 HashMap 记录索引后，`left` 可以直接跳到正确位置，总步数严格为 n。

## 五、易错点与注意事项

### 新手常犯的 5 个错误

**❌ 错误 1：混淆"子串"和"子序列"**

> **子串**（substring）是**连续**的，比如 `"abc"` 是 `"xabcy"` 的子串
> **子序列**（subsequence）可以**不连续**，比如 `"ac"` 是 `"abc"` 的子序列
> 本题要求的是**子串**，所以滑动窗口维护的必须是连续区间

**❌ 错误 2：left 没有取 max，导致回退**

```python
# 错误写法：
if char in char_index:
    left = char_index[char] + 1  # ❌ left 可能反而变小了！

# 正确写法（方案 A：加 >= left 判断）：
if char in char_index and char_index[char] >= left:
    left = char_index[char] + 1

# 正确写法（方案 B：取 max）：
if char in char_index:
    left = max(left, char_index[char] + 1)
```

**反例**：`s = "abba"`
- 当 `right=3`（第二个 `'a'`），`char_index['a'] = 0`，此时 `left = 2`
- 如果直接 `left = 0 + 1 = 1`，left 从 2 回退到了 1，窗口又包含了重复的 `'b'`！

**❌ 错误 3：忘记处理空字符串**

```python
# 如果不判断空字符串，虽然代码不会报错（for 循环不会执行），
# 但养成处理边界的习惯非常重要，面试中这是加分项
```

**❌ 错误 4：用 HashSet 时忘记删除元素**

如果使用 HashSet 而非 HashMap 的方案，左边界移动时必须把移出窗口的字符也从 Set 中删除，否则会误判重复。

**❌ 错误 5：窗口长度计算错误**

```python
# 错误：right - left（少算了 1）
# 正确：right - left + 1
# 因为区间 [left, right] 包含两个端点
```

### 避坑建议

1. **"abba" 是试金石**：这个用例能检测出 `left` 回退的 bug，调试时优先用它
2. **画图模拟**：遇到窗口类问题，先在纸上画出窗口的移动过程，标注 left/right 的变化
3. **先写 HashSet 版本，再优化为 HashMap 版本**：HashSet 版本逻辑更直观，理解后再做跳跃优化
4. **检查"是否有遗漏更新"**：无论是否发生重复，`char_index[char] = right` 都必须执行

### 通用解题模板

所有**滑动窗口**题目都可以套用以下框架：

```python
def sliding_window(s):
    # 1. 初始化窗口状态（哈希表 / 计数器 / 变量）
    window_state = {}
    left = 0
    result = 0  # 或初始化为极值

    # 2. 右边界不断扩展
    for right in range(len(s)):
        char = s[right]

        # 3. 更新窗口状态（加入新字符）
        # ... 更新 window_state ...

        # 4. 判断是否需要收缩左边界
        while 窗口不满足条件:
            # 移除左边界字符，更新状态
            left += 1

        # 5. 更新结果（在窗口合法时记录答案）
        result = max(result, right - left + 1)  # 或其他更新逻辑

    return result
```

**核心要点**：
- **何时扩展**：右边界始终右移（外层 for 循环）
- **何时收缩**：当窗口不满足题目条件时收缩左边界（内层 while 循环）
- **何时记录答案**：在窗口合法的状态下更新结果
- **不同题目的差异**：主要在于"窗口合法的条件"和"更新结果的方式"不同

掌握这个模板后，遇到滑动窗口题只需思考两个问题：
1. **窗口的合法条件是什么？**（本题：窗口内没有重复字符）
2. **要记录的结果是什么？**（本题：合法窗口的最大长度）
