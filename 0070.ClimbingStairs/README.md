# 70. 爬楼梯：动态规划的基石

## 1. 审题（Problem）

### 1.1 约束解码
假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。
每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶呢？
*   `1 <= n <= 45`。数据规模很小，但如果不优化，$O(2^n)$ 会超时。

### 1.2 边界陷阱
*   `n=1`：只有 1 种方法。
*   `n=2`：有 2 种（1+1 或 2）。

### 1.3 问题归类
*   **动态规划 (Dynamic Programming)**。
*   **斐波那契数列 (Fibonacci Sequence)**。

## 2. 思维演化（Reasoning）

### 2.1 方案 A：递归（回溯）
我们要到第 `n` 阶，最后一步只能是从 `n-1` 迈 1 步上来，或者从 `n-2` 迈 2 步上来。
所以 `f(n) = f(n-1) + f(n-2)`。
这不就是斐波那契数列吗？
直接递归会产生大量重复计算（例如计算 `f(5)` 需要算 `f(4)` 和 `f(3)`，计算 `f(4)` 又要算 `f(3)`...）。

### 2.2 方案 B：记忆化搜索
用一个数组 `memo` 存下已经计算过的结果。时间复杂度从 $O(2^n)$ 降为 $O(n)$。

### 2.3 方案 C：动态规划（滚动数组）
既然只需要前两个状态，何必存整个数组？
我们只需要两个变量 `prev` 和 `curr`，一边遍历一边更新。

## 3. 直觉培养（Intuition）

### 3.1 跨越时空的跳跃
站在第 `i` 级台阶上回头看。
*   如果你是从第 `i-1` 级上来的，那你其实继承了到达 `i-1` 级的所有路径。
*   如果你是从第 `i-2` 级上来的，那你继承了到达 `i-2` 级的所有路径。
*   这两类路径是**互斥且完备**的（最后一步步长不同）。

![爬楼梯动画](animation.mp4)

**可视化重点**：
1.  **楼梯**：展示 0 到 n 的阶梯。
2.  **累加**：第 `i` 阶的值 = 第 `i-1` 阶的值 + 第 `i-2` 阶的值。
3.  **生长**：随着 `i` 的增加，这一规律不断向后传递。

## 4. 代码实现（Solution）

### 4.1 滚动数组版本（极致空间优化）

```go
func climbStairs(n int) int {
	if n <= 2 {
		return n
	}

	// 初始化 dp[1] 和 dp[2]
	// p (prev) 代表 dp[i-2]
	// q (curr) 代表 dp[i-1]
	p, q := 1, 2

	for i := 3; i <= n; i++ {
		// dp[i] = dp[i-1] + dp[i-2]
		sum := p + q
		
		// 滚动更新
		p = q
		q = sum
	}

	return q
}
```

### 4.2 复杂度分析
*   **时间复杂度**: $O(n)$。一次循环。
*   **空间复杂度**: $O(1)$。只用了常数个变量。

### 5.2 斐波那契的本质
斐波那契数列不仅出现在自然界（花瓣数、兔子繁殖），也是计算机科学中**分治**与**状态转移**的最简模型。掌握它，就掌握了动态规划的入门钥匙。
