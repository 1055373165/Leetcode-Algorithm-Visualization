# 283. Move Zeroes：零元素的滚雪球

![Move Zeroes Animation](animation.mp4)

## 1. 审题（Problem）

### 1.1 约束解码
给定一个数组 `nums`，编写一个函数将所有 `0` 移动到数组的末尾，同时保持非零元素的相对顺序。
*   **必须在原数组上操作**：不能拷贝额外的数组，空间复杂度限制为 $O(1)$。
*   **保持相对顺序**：这是关键约束，意味着不能简单地用 Partition（如快排的划分）逻辑，因为快排划分不稳定。

### 1.2 边界陷阱
*   数组为空或只有一个元素。
*   数组全是 `0` 或全是 非 `0`。
*   `0` 在开头、中间或结尾。

### 1.3 问题归类
数组原地操作，通常涉及 **双指针（Two Pointers）**。
具体来说，是 **快慢指针** 或 **读写指针** 模式。

## 2. 思维演化（Reasoning）

### 2.1 暴力解法
创建一个新数组，遍历原数组，先把非零元素放进去，然后再填 `0`。
最后把新数组拷贝回原数组。
*   时间复杂度：$O(N)$。
*   空间复杂度：$O(N)$。违反了“原地操作”的约束。

### 2.2 优化演化链
想要原地操作，我们可以记录“当前可以放置非零元素的位置”。
想象我们在整理书架，要把所有的红书移到左边，空位留给蓝书。
我们用一个指针 `left` 指向“下一个存放非零数的位置”，用 `right` 遍历数组。
当 `right` 遇到非零数时，就把它放到 `left` 的位置，然后 `left` 往前走一步。

### 2.3 两种流派
1.  **覆盖（Overwrite）**：
    *   遍历一遍，把所有非零数按顺序填到前 `k` 个位置。
    *   遍历剩下的位置 `k` 到 `n-1`，全部填 `0`。
    *   缺点：如果数组全是 `0`，这种方法会对每个位置写两次（先写非零，后填充），写操作较多。
2.  **交换（Swap）**：
    *   遍历时，如果 `nums[right] != 0`，则交换 `nums[left]` 和 `nums[right]`。
    *   这样 `left` 左边永远是非零数，`left` 到 `right` 中间永远是 `0`（就像一个滚雪球，`0` 的区域在滚动中变大）。
    *   优点：更能体现“移动”的物理意义，且对全非零数组，仅需一次遍历且无多余写入。

## 3. 直觉培养（Intuition）

### 3.1 滚雪球（Snowball）
想象 `0` 是一起滚动的雪球。
*   初始时，雪球大小为 0。
*   当遇到 `0` 时，雪球变大（`right` 前进，`left` 不懂，区间变大）。
*   当遇到 `非0` 时，非零元素需要“跳过”整个雪球来到雪球的前面（`Swap`），雪球整体向后滚动一步（`left` 和 `right` 都前进）。

## 4. 代码实现（Solution）

### 4.1 核心代码（Go）

```go
func moveZeroes(nums []int) {
	left := 0 // 插入位置 (Insert Position)

	for right := 0; right < len(nums); right++ {
		if nums[right] != 0 {
			// 只有当左右指针不重合时才需要交换（优化点）
			// 但直接交换代码更简洁
			if left != right {
				nums[left], nums[right] = nums[right], nums[left]
			}
			left++
		}
	}
}
```

### 4.2 复杂度分析
*   **时间复杂度**：$O(N)$。遍历一次数组。
*   **空间复杂度**：$O(1)$。只用了两个指针变量。

### 4.3 易错点
*   **指针定义**：`left` 既是非零数的尾部，也是下一个非零数的插入位置。
*   **全0与全非0**：代码应当能自然处理这些情况。

### 5.2 模板沉淀：读写双指针
```go
func processArray(nums []int) int {
    write := 0
    for read := 0; read < len(nums); read++ {
        if condition(nums[read]) {
            nums[write] = nums[read] // 覆盖 or 交换
            write++
        }
    }
    return write // 返回新长度
}
```
