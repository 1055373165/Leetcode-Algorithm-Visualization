# 128. 最长连续序列：哈希表的“跳跃”艺术

## 1. 审题（Problem）

### 1.1 约束解码
给定一个未排序的整数数组 `nums`，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。
**硬性要求**：时间复杂度为 **$O(n)$**。

### 1.2 边界陷阱
*   **空数组**：返回 0。
*   **重复元素**：`[1, 2, 0, 1]` 应该算作 `0, 1, 2`，长度为 3。Set 天然可以去重。
*   **乱序**：输入 `[100, 4, 200, 1, 3, 2]`，输出 4（`1, 2, 3, 4`）。

### 1.3 问题归类
*   如果允许 $O(n \log n)$：直接排序，然一次遍历数个数，简单。
*   既然要求 $O(n)$：必须禁掉排序。这意味着我们不能改变数组顺序，只能通过额外的“查找”来建立联系。
*   **O(1) 查找**：哈希表（Set）是唯一选择。

## 2. 思维演化（Reasoning）

### 2.1 暴力解法：枚举起点
对每个数 `x`，我们可以尝试往后找 `x+1`, `x+2`, ... 是否存在。
每一次查找都需要遍历整个数组，复杂度 $O(n^2)$。太慢。

### 2.2 哈希优化：查找加速
为了加速查找，先把所有数扔进 HashSet。
现在对每个数 `x`，查找 `x+1` 只需要 $O(1)$。
似乎复杂度变成了 $O(n)$？
并不完全是。如果数组是 `5, 4, 3, 2, 1`：
*   处理 5：找 6（无）。长度 1。
*   处理 4：找 5（有），找 6（无）。长度 2。
*   ...
*   处理 1：找 2, 3, 4, 5。长度 5。
最坏情况下，这是一个等差数列求和，复杂度还是 $O(n^2)$。

### 2.3 关键跳跃：只当“头”
我们发现，在上面的例子中，`2, 3, 4, 5` 都被重复计算了多次。
事实上，只有当 `1` 是序列的**起点**时，我们才需要去统计长度。
**如何判断 `x` 是不是起点？**
很简单：如果 `x-1` 存在，那 `x` 肯定不是起点（它前面的 `x-1` 会把它包进去）。
如果 `x-1` 不存在，那 `x` 就是起点，这时我们才开始 `while (set.contains(x+1))` 的循环。

## 3. 直觉培养（Intuition）

### 3.1 链式反应
想象数组是一堆散落的拼图。
1.  我们先把所有拼图块都倒在桌子上（存入 Set）。
2.  拿起一块拼图（`x`），看看它左边有没有扣（`x-1`）。
    *   如果有：说明它不是最左边的那块，先放回去，以后处理 `x-1` 时自然会连上它。
    *   如果没有：说明它是最左边的头！好，那我们就从它开始，疯狂往右拼（找 `x+1`, `x+2`...），直到断掉。

## 4. 代码实现（Solution）

```go
func longestConsecutive(nums []int) int {
	// 1. 放入 Set 去重且提供 O(1) 查询
	numSet := make(map[int]bool)
	for _, num := range nums {
		numSet[num] = true
	}

	longestStreak := 0

	// 2. 遍历 Set 中的每个数（去重后的）
	for num := range numSet {
		// 3. 核心剪枝：只有当 num-1 不存在时，才开始计数
		if !numSet[num-1] {
			currentNum := num
			currentStreak := 1

			// 4. 不断向后寻找
			for numSet[currentNum+1] {
				currentNum++
				currentStreak++
			}

			if currentStreak > longestStreak {
				longestStreak = currentStreak
			}
		}
	}

	return longestStreak
}
```

### 4.2 复杂度证明
*   **时间复杂度**: $O(n)$。
    *   虽然有 `for` 循环套 `while` 循环，但仔细看逻辑：
    *   `if !numSet[num-1]` 保证了每个序列只会被**从头遍历一次**。
    *   例如 `[1, 2, 3]`：`2` 和 `3` 都会被 `if` 拦住，只有 `1` 会进入 `while` 循环遍历 `1->2->3`。
    *   每个元素最多被访问两次（一次放入 Set，一次被 while 循环计数）。所以是严格的 $O(n)$。
*   **空间复杂度**: $O(n)$。用于存储 HashSet。

### 4.3 易错点清单
1.  **遍历对象**：遍历 `numSet` 比遍历 `nums` 稍微好一点（因为去重了），但遍历 `nums` 也完全正确。
2.  **当前长度重置**：每次发现新起点，都要把 `currentStreak` 重置为 1。
3.  **空数组**：代码中初始化 `longestStreak = 0` 涵盖了空数组的情况。

## 5. 融会贯通（Mastery）

### 5.1 变体题群
这道题比较独特，没有什么直接的变体，但其核心思想——**利用 Set 进行 O(1) 连通性检查**——非常常用。
例如：**岛屿数量**（DFS/BFS找连通分量），这道题其实是一维版的“找最大连通分量”。

### 5.2 模式识别
当题目要求：
1.  **未排序数组**
2.  **O(n) 时间复杂度**
3.  **寻找某种关系（连续、配对）**
通常解法就是：**HashSet**。
如果还涉及“范围”、“合并”，也可以考虑 **并查集 (Union Find)**，但这道题用 Set 最简单。
