# 6. Z 字形变换 (ZigZag Conversion)

## 1. 30 秒面试回答

这题是**字符串找规律**。把字符按 Z 字形排列后逐行读取。核心不变量：Z 字形有固定周期 `cycle = 2*(numRows-1)`，每个周期内第 `i` 行贡献 1 或 2 个字符，下标可直接算出。O(n) 时间 O(n) 空间，因为外层遍历 numRows 行、内层每个字符恰好被访问一次，总共 n 次。

## 2. 我第一眼应该先想到什么

**信号词**：「Z 字形排列」「按行读取」—— 纯模拟/找规律题，不涉及搜索、DP、数据结构。

**暴力起点**：建 `numRows × n` 二维矩阵，模拟 Z 字形填入，再逐行读取。

**暴力慢在哪**：矩阵大量空位浪费 O(numRows × n) 空间，且遍历整个矩阵读取时要跳过空位。虽然时间仍 O(n)，但面试官会追问"你能不用矩阵吗？"——这才是真正的考点。

## 3. 核心洞察

### 面试官想考什么

面试官想看你能不能**跳过模拟，直接用数学规律按行提取字符**。考察从具象到抽象的推导能力。

### 解法分离判断

这题存在**快速稳妥解**和**面试官期望解**的分离：

- **「解法一：快速稳妥解」**（模拟法）：用 `curRow` + `goingDown` 反弹收集到 numRows 个桶，拼接。不容易写错因为逻辑直觉化，不需要推导公式。
- **「解法二：面试官期望解」**（数学周期法）：外层循环行号 i，内层循环周期起点 j，直接计算 `s[j+i]` 和 `s[j+cycle-i]`。面试官更想看到这个因为它展示了对 Z 字形周期结构的数学理解。

**面试策略：先给模拟法拿到基本分，再主动说"我观察到这里有周期性，可以直接按行计算下标"，切到数学法展示深度。**

### 关键不变量

`cycle = 2 * (numRows - 1)`。一个周期内：
- 首行和末行：各 1 个字符（位置 `j+i`）
- 中间第 `i` 行：2 个字符（位置 `j+i` 和 `j+cycle-i`）

理解了周期结构，整题就是按公式遍历。

### 为什么不会漏解

外层枚举所有行，内层枚举所有周期起点。每个字符在 Z 字形中恰好属于某一行的某个周期，因此恰好被访问一次。

### 容易误判的方向

以为需要 `row, col` 双坐标追踪——不需要，列信息在结果中完全没用。

## 4. 最优解怎么一步步长出来

### 解法一：快速稳妥解（模拟法）

1. **暴力**：建二维矩阵
2. **观察**：结果只需要每行的字符序列，不需要列位置
3. **方案**：`curRow` 从 0 到 numRows-1 反弹，每个字符扔进 `rows[curRow]`

### 解法二：面试官期望解（数学周期法）

1. **观察**：Z 字形重复周期为 `cycle = 2*(numRows-1)`
2. **规律**：画图发现第 `i` 行每周期最多贡献 2 个字符
3. **公式**：第一个 `j+i`，第二个 `j+cycle-i`（首尾行只有第一个）
4. **关键**：当 `i == 0` 或 `i == numRows-1` 时，`j+i == j+cycle-i`，所以只取一个

**最容易想错的岔路**：中间行第二个字符位置是 `j + cycle - i`，不是 `j + cycle - i - 1`。

## 5. 手推关键样例

**样例**：`s = "PAYPALISHIRING"`, `numRows = 4`，`cycle = 6`

**此样例贯穿 Section 6 和 Section 7。**

Z 字形布局：
```
P     I     N       → 行0
A   L S   I G       → 行1
Y A   H R           → 行2
P     I             → 行3
```

数学法视角（关键步骤）：

| 行 i | 公式 | 提取的字符 |
|------|------|-----------|
| 0 | j+0: s[0], s[6], s[12] | P, I, N |
| 1 | j+1: s[1], s[7], s[13]; j+5: s[5], s[11] | A, **L**, S, **I**, G |
| 2 | j+2: s[2], s[8]; j+4: s[4], s[10] | Y, **A**, H, **R** |
| 3 | j+3: s[3], s[9] | P, I |

**关键转折**：行1 在 j=0 时取 `s[0+1]=A` 和 `s[0+6-1]=s[5]=L`。两个字符间距分别是 `cycle-2i=4` 和 `2i=2`。

结果：`PINALSIGYAHRPI`

## 8. Go 代码

### 解法一：快速稳妥解（模拟法）

```go
func convert(s string, numRows int) string {
	if numRows == 1 || numRows >= len(s) {
		return s
	}

	rows := make([][]byte, numRows)
	curRow := 0
	goingDown := false

	for i := 0; i < len(s); i++ {
		rows[curRow] = append(rows[curRow], s[i])
		// 到顶或到底时反弹方向
		if curRow == 0 || curRow == numRows-1 {
			goingDown = !goingDown
		}
		if goingDown {
			curRow++
		} else {
			curRow--
		}
	}

	ans := make([]byte, 0, len(s)) // 预分配：结果长度 = 输入长度
	for _, row := range rows {
		ans = append(ans, row...)
	}
	return string(ans)
}
```

**Go 惯用写法要点**：
- 按 `byte` 处理而非 `rune`：题目明确输入是英文字母+逗号+句号，纯 ASCII
- `ans` 预分配 `len(s)` 容量：结果字符数 = 输入字符数，避免扩容
- `goingDown` 取反用 `!goingDown` 而非 `goingDown = !goingDown` 加 if-else

### 解法二：面试官期望解（数学周期法）

```go
func convert(s string, numRows int) string {
	if numRows == 1 || numRows >= len(s) {
		return s
	}

	n := len(s)
	cycle := 2 * (numRows - 1)
	ans := make([]byte, 0, n)

	for i := 0; i < numRows; i++ {
		for j := 0; j+i < n; j += cycle {
			ans = append(ans, s[j+i])
			// 中间行每周期有第二个字符
			if i > 0 && i < numRows-1 && j+cycle-i < n {
				ans = append(ans, s[j+cycle-i])
			}
		}
	}
	return string(ans)
}
```

**Go 惯用写法要点**：
- `ans` 预分配 `n` 容量，一次分配不扩容
- 外层 `i` 是行号，内层 `j` 是周期起点——变量名语义清晰
- 边界检查 `j+cycle-i < n` 在 `&&` 短路链中最后，避免越界

**面试加分项**：这题按 `byte` 下标访问 `s[j+i]` 而非 `range` 遍历，因为需要随机访问。Go 中 `string` 支持按 byte 下标直接读取，不需要转 `[]byte`。

## 9. 最容易写错的地方

1. **`numRows == 1` 忘特判**：`cycle = 2*(1-1) = 0`，数学法内层 `j += cycle` 死循环。这是最常见的 runtime error
2. **中间行第二个字符下标**：是 `j + cycle - i`，不是 `j + cycle - i - 1`。画图验证：行1第二个字符是 s[5]，即 `0 + 6 - 1 = 5` ✓
3. **模拟法方向切换时机**：必须在**移动之前**翻转 `goingDown`。如果先移动再判断，第 0 行和最后一行会少收集字符
4. **`numRows >= len(s)` 边界**：此时 Z 字形只有一列，直接返回原串。不特判虽不会出错但会做无用计算
5. **面试官追问**："从结果反推原串？" —— 用相同周期公式计算每行字符数，然后从结果中按行切分、反向填充
